CÁCH BIÊN DỊCH
========================================================
Yêu cầu: g++ >= 15.2.0 
Biên dịch:
    g++ -std=c++20 game.cpp -o game.exe
Dòng lệnh:
    g++ -std=c++20 -Wall -Wextra game.cpp -o game.exe
========================================================
CÁCH CHẠY CHƯƠNG TRÌNH
========================================================
Chạy bình thường:
    ./game.exe
Chạy chế độ judge:
    ./game.exe --judge --input input.txt
Chạy test Grader:
    python grader.py --target game
